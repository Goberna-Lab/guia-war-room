# Guía del alumno · War Room

Presentación en HTML puro (sin dependencias ni build) que explica cómo ingresa un alumno al simulador
War Room de Goberna y qué hace dentro: ingreso, comando y rol, perfil del candidato, contenido,
encuestas y zona de debates.

- Se abre con `index.html`. Flechas ← → para avanzar, `F` para pantalla completa.
- Las capturas de `media/` son de **cuentas de prueba** en un entorno local; no hay datos de alumnos.
- Los textos y las reglas del puntaje salen de la documentación del propio War Room.
